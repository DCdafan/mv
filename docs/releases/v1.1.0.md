## 拾光MV 1.1.0

面向影楼写真、蛋糕烘焙门店的桌面端 MV 制作软件。

### 新增：蛋糕店场景
- 3 套烘焙模板：甜蜜烘焙、新品上市、法式下午茶（默认竖屏 9:16）
- 照片按「品名-价格」命名（如 `草莓奶油蛋糕-168.jpg`），自动显示品名和价格
- 产品卡、产品大图、菜单板版式；价格爆炸贴、丝带标签
- 编辑器可逐场景修改品名、价格、标签
- 品牌设置新增门店地址、电话前缀（预约热线 / 订购热线）

### 已有功能
- 13 套模板、26 种转场，16:9 / 9:16 / 1:1 / 4:3
- 智能选片（人脸、闭眼、模糊、重复检测）、音乐自动卡点
- 时间线编辑器、撤销重做、批量出片、720p–4K 硬件加速导出

### 安装
- 下载 `ShiguangMV-1.1.0-arm64.dmg`，仅支持 **Apple 芯片（M1 及以后）的 Mac**
- 安装包未签名：首次打开请在「应用程序」里**右键 → 打开**，或在「系统设置 → 隐私与安全性」里点「仍要打开」
