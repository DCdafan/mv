## 拾光MV 1.2.0

### 新增模板（共 18 套）
- **圣诞快乐**：飘雪、圣诞树与礼物盒，配《铃儿响叮当》
- **新春团圆**：福字、鞭炮、灯笼、夜空烟花，卡点闪光
- **生日派对**：气球彩纸、蛋糕蜡烛，配《生日快乐歌》
- **告白时刻**：爱心飘升、玫瑰与爱心相框，逐字浮现告白
- **萌宠日记**：爪印与骨头、拍立得手写字幕

### 新功能
- **逐字文字动画**：弹出、落下、浮起、淡入、模糊聚焦、放大、打字机、波浪；多套模板的片头标题已启用
- **卡点特效**：重拍时画面缩放脉冲 / 闪光，可在项目设置里切换
- **全局滤镜**：原片、清新、暖阳、日系、胶片、鲜艳、冷调、黑白
- **导出封面图**：把当前画面按成片分辨率存为 PNG
- **新增 8 种转场**（共 34 种）：中开、斜向擦除、扭曲推进、旋转模糊、方格翻转、圆点溶解、星形展开、扫光
- **新增烟花粒子**，以及圣诞树、礼物盒、雪花、福字、鞭炮、爪印、骨头、玫瑰等装饰
- 内置曲库新增 2 首公有领域音乐

### 改进
- 字幕显现速度按场景时长自动调整，短场景不会出现字幕显示不全

### 安装
- 下载 `ShiguangMV-1.2.0-arm64.dmg`，仅支持 **Apple 芯片（M1 及以后）的 Mac**
- 安装包未签名：首次打开请在「应用程序」里**右键 → 打开**，或在「系统设置 → 隐私与安全性」里点「仍要打开」
