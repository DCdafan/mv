## 拾光MV 1.3.0

### AI 助手（需要在「AI 设置」里填写 OpenAI 或兼容接口的 API Key）
- **AI 写文案**：看懂每张照片，写字幕、商品卖点、片头标题和片尾寄语
- **AI 推荐模板和音乐**：新建向导和编辑器里都能用
- **AI 故事线排序**：按情节排列照片，高光照片自动放到满屏大画面
- **AI 旁白**：写旁白稿并合成语音，背景音乐在旁白期间自动压低；也可以导入自己录的旁白
- 只发送 360px 缩略图；API Key 用系统钥匙串加密保存

### 新功能
- **照片 + 视频混剪**：支持 MP4 / MOV，视频片段和照片一起编排、卡点
- **人物 / 宠物 3D 视差**：本地抠出主体，前后景分层运镜
- **贴纸库**：36 种贴纸 + 5 种文字样式，画面上直接拖动缩放，7 种动画
- **文字样式**：模板里的文字可以单独改字体、颜色、大小
- **自定义 Logo**：片尾店名上方和右下角水印
- **时间线拖拽调时长**：自动吸附节拍
- **音乐选段**：在整首歌的波形上选起点，或一键自动选高潮
- **一键多版本导出**：完整版 + 15 秒精华版（可竖屏）+ 封面图
- **我的模板**：保存模板、滤镜、卡点、音乐、文案等设置，新建时直接选用

### 改进与修复
- 重新编排（换模板、换一换、重新卡点）时保留手动加的贴纸和改过的文字
- 暂停预览时不再停在黑场；重新编排后停在片头标题出现的位置
- 分析音乐不再依赖声卡，避免音频设备异常导致分析失败

### 说明
- AI 功能在本地模拟接口上完整测试过；真实接口需要填写你自己的 Key，模型名可在「AI 设置」里修改
