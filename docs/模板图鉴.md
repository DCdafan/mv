# 模板图鉴

影楼类模板用的是同一组婚纱测试照片，烘焙类模板用的是蛋糕商品照片（文件名带品名和价格）。每张图是测试照片套用该模板后，每个场景中间时刻的一帧（从左到右、从上到下依次为片头、正片各场景、片尾）。片尾里的「拾光摄影工作室」和电话来自品牌设置，右下角是可选水印。

图片由 `node e2e/gallery.mjs` 自动生成。
