# 拾光 MV · 产品设计

> 面向影楼 / 摄影工作室的桌面端 MV 电子相册制作软件：导入客片 → 选模板 → 自动卡点成片 → 精修 → 批量导出。

## 1. 对标产品

| 产品 | 定位 | 我们借鉴什么 |
|---|---|---|
| ProShow Producer（已停更） | 国内影楼十几年来的主力 MV 工具（"PSP 影楼模板"） | 场景 / 转场 / 图层 / 关键帧的专业编辑模型；"样式"可复用 |
| SmartSHOW 3D、PTE AV Studio | ProShow 停更后的现代替代 | 大量现成模板、5 分钟成片向导、3D 动效 |
| 视频秀秀、传影记、印象电子相册（手机） | 一键成片 | 选模板 → 替换照片 → 出片，零学习成本 |
| 剪映"一键成片" | AI 自动卡点 | 音乐节拍分析、按拍点切换画面 |

影楼的实际工作流有几个和 C 端不同的痛点，这是我们的差异化：

1. **量大**：一个客户 50～300 张精修片，一天要出很多客户 → 需要**批量出片**和**智能选片**（去重、去模糊、去闭眼）。
2. **品牌**：片尾要有影楼 Logo、名称、电话，画面要有水印 → 需要**品牌设置**。
3. **多平台**：横屏给电视 / 大屏，竖屏发抖音和朋友圈 → 同一套模板支持 **16:9 / 9:16 / 1:1**。
4. **离线、高清**：原图动辄 20MB 以上，必须本地渲染，支持 4K 导出。

## 2. 核心流程

```
导入照片 ─► 智能分析（人脸 / 清晰度 / 闭眼 / 重复 / 横竖）
   │
选择模板 ─► 选择音乐（模板推荐 / 曲库 / 本地导入）─► 节拍分析
   │
填写信息（标题、新人姓名、日期、结尾语、画幅）
   │
自动编排：照片按横竖分配到版式，时长对齐小节，高分照片放在副歌高潮
   │
编辑器精修：换版式、换照片、改字幕、调焦点、改转场、拖动排序
   │
导出 MP4（720p / 1080p / 4K，25 / 30 / 60fps）· 导出队列 · 批量出片
```

## 3. 功能清单

- **首页**：最近项目、新建 MV（向导）、批量出片、模板中心、品牌设置
- **新建向导**：4 步，最快 3 次点击出片
- **编辑器**
  - 左栏：照片库（分析标记、排除 / 恢复、拖入场景）、模板、音乐、转场、滤镜
  - 中间：实时预览播放器（WebGL，实时 60fps）
  - 右栏：场景属性（版式切换、照片槽位、焦点、时长〔按拍〕、转场、文字）
  - 底部：时间线（场景卡片、转场标记、音乐波形、节拍刻度、播放头、拖动排序）
  - 撤销 / 重做、换一换（同模板重新随机编排）、一键换模板（保留照片和文字）
- **导出**：分辨率、帧率、画幅、码率；硬件编码；导出队列在后台进行
- **批量出片**：选一个根目录，每个子文件夹对应一个客户，全部套用同一模板和音乐，排队导出
- **品牌**：影楼名称、Logo、口号、电话，可选角标水印

## 4. 技术架构

| 层 | 选型 | 理由 |
|---|---|---|
| 桌面框架 | Electron + electron-vite + React + TypeScript | 跨 Mac / Win，生态成熟 |
| 状态 | Zustand + 快照式撤销栈 | 项目 JSON 体量小，快照简单可靠 |
| 渲染引擎 | 自研 WebGL2 引擎 | 预览和导出共用同一个 `renderFrame(project, t)`，保证所见即所得 |
| 转场 | 自写 GLSL 着色器（20+ 种） | 心形、圆形、溶解、旋涡、立方体、光斑、故障等 |
| 粒子 | 确定性粒子系统（由时间推算，可任意跳帧） | 花瓣、雪花、爱心、星光、气泡、彩纸、光斑 |
| 文字 | Canvas2D 排版生成纹理 | 中文字体、描边、阴影、逐字动画 |
| 音乐分析 | Web Worker：频谱通量 → 节奏估计 → 动态规划节拍追踪 → 能量曲线 | 不依赖 Python，离线可用 |
| 照片分析 | MediaPipe 人脸关键点（含闭眼）+ 拉普拉斯方差清晰度 + dHash 去重 + EXIF | 全部本地运行 |
| 导出 | 隐藏渲染窗口 + WebCodecs 硬件 H.264 编码 + mp4-muxer → FFmpeg 合成音轨（淡出） | 速度快，后台排队，不卡界面 |
| 本地文件 | 自定义 `mvfile://` 协议 + 代理图缓存 | 安全隔离，大图秒开 |

### 模板数据模型（简化）

```ts
Template {
  id, name, category, palette, fonts, grade(调色), background, overlays(全局粒子),
  transitions: [{ name, weight, beats }],
  intro, outro: SceneStyle,          // 片头 / 片尾
  styles: SceneStyle[]               // 版式池
}
SceneStyle {
  slots: ['landscape' | 'portrait' | 'any'][],   // 需要几张、什么方向的照片
  energy: [min, max],                            // 适合音乐的哪种能量段
  layers(aspect): Layer[]                        // 按画幅生成图层：photo / text / shape / decor / particles
}
```

模板是纯数据，后续可以做"模板编辑器"给设计师用，模板也可以云端下发。

## 5. 里程碑

1. **M1 引擎**：WebGL 渲染、转场、粒子、文字、调色
2. **M2 智能**：节拍分析、照片分析、自动编排
3. **M3 模板**：10 套模板（婚纱 ×3、儿童 ×2、旅行、时尚、胶片、毕业、杂志）
4. **M4 编辑器**：完整编辑界面 + 撤销 / 重做 + 项目保存
5. **M5 导出**：导出队列、批量出片、品牌水印
6. **M6 打包**：macOS dmg（后续加 Windows）
